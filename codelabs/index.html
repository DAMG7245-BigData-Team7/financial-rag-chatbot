A production‑ready Financial Concept Note Generator that:

  • Retrieves chunks from a hybrid Pinecone index (dense OpenAI embeddings + sparse BM25) and reranks (optional).
  • Generates structured concept notes using instructor + Pydantic.
  • Caches notes in PostgreSQL (Cloud SQL) to reduce cost/latency.
  • Falls back to Wikipedia content if the domain corpus yields low/zero recall.
  • Exposes an API via FastAPI on Cloud Run and a Streamlit UI (also on Cloud Run).
  • Schedules ingestion + pre‑seeding via Airflow (Cloud Composer).
  • Provisions infra with Terraform and CI/CD via GitHub Actions.
  • Python 3.10+ and Docker
  • Accounts/keys: OpenAI, Pinecone
  • GCP project with Cloud Run, Cloud SQL, Cloud Composer, IAM, GCS
  • Optional: Homebrew (macOS) or Go toolchain for claat

FastAPI (app/main.py)

  • GET /health → service status + dependency checks (Pinecone, Postgres).
  • POST /query → Core: input concept (and optional force_refresh), returns ConceptNote.
    1. Cache check (Postgres): if exists and not force_refresh → return cached.
    2. RAG retrieval: Hybrid search from Pinecone via RAGService.retrieve_documents(...).
    3. Context assembly: joins top chunks into a context string.
    4. Structured generation: InstructorService.generate_note(context, concept) → Pydantic‑validated ConceptNote.
    5. Persist: store note JSON + sources_used in Postgres.
    6. Return response.
  • DELETE /cache/{concept} → remove a cached concept.
  • GET /cache → list cached concepts.
  • GET /stats → cache size, hit rate, recent queries.

Streamlit UI (frontend/app.py)

  • Submits to POST {FASTAPI_URL}/query.
  • Renders the structured note and shows cached/new status.

wikipedia_service.py is used when:

  • Retrieval returns no chunks or confidence is insufficient (few distinct sources/short context).
  • Fetch a summary (and first paragraphs if needed), truncate to safe limit.
  • Generation uses this context; mark provenance with source="wikipedia" and label sources_used.

Create .env in repo root:

OPENAI_API_KEY=...
PINECONE_API_KEY=...
PINECONE_INDEX_NAME=fintbx-hybrid-3072
DATABASE_URL=postgresql+psycopg2://postgres:postgres@localhost:5432/aurelia_db
# or: sqlite:///./aurelia.db

Install + run:

# API
cd app && pip install -r requirements.txt
uvicorn main:app --reload --host 0.0.0.0 --port 8080

# Frontend
cd ../frontend && pip install -r requirements.txt
streamlit run app.py --server.port 8501

Smoke test:

curl -X POST http://localhost:8080/query \
  -H "Content-Type: application/json" \
  -d '{"concept": "Discounted Cash Flow", "force_refresh": false}'

Airflow (Composer):

  • dags/fintbx_ingest_dag.py → parse + hybrid upload
  • dags/concept_seed_dag.py → pre‑warm cache by calling /query
  1. Build & push images
gcloud auth configure-docker
docker build -t gcr.io/$PROJECT/aurelia-api:latest ./app && docker push gcr.io/$PROJECT/aurelia-api:latest
docker build -t gcr.io/$PROJECT/aurelia-ui:latest  ./frontend && docker push gcr.io/$PROJECT/aurelia-ui:latest
  1. Terraform
# terraform/terraform.tfvars
project_id       = "YOUR_GCP_PROJECT"
region           = "us-east1"
db_instance_name = "aurelia-postgres"
db_user          = "aurelia_user"
db_password      = "CHANGE_ME"

frontend_image   = "gcr.io/YOUR_GCP_PROJECT/aurelia-ui:latest"
app_name         = "aurelia"

cd terraform
terraform init
terraform apply -auto-approve
  1. Cloud Run ↔ Cloud SQL
  • Grant Cloud Run service account Cloud SQL Client.
  • Use Unix socket URL for DATABASE_URL:
postgresql+pg8000://aurelia_user:${DB_PASSWORD}@/aurelia_db?host=/cloudsql/${DB_CONN_NAME}
  1. Composer DAGs
  • Sync ./dags to Composer's bucket (or use the GitHub workflow).
  • /health checks Pinecone + Postgres.
  • Log and track cache hit rate, token usage, and latency.
  • Add BigQuery sink or GCS logs for analysis.
  • 500 on /query: verify keys, index name, DB connectivity.
  • No RAG context: ensure hybrid index populated and namespace correct.
  • High latency: warm cache via seed DAG; consider smaller model / disable reranker.
  • Composer deps: add missing PyPI packages to environment config.
